# 🏢 Talent Carpet - HR Consultancy & Recruitment Platform

> **Talent Carpet** is a full-stack web application (React, Node.js, Express.js, MySQL / Sequelize) designed for an enterprise HR Consultancy firm in Chennai, India. It provides seamless recruitment management, candidate sourcing, client proposal processing, automated AI assistant support, and a comprehensive administration dashboard.

## 🚀 Tech Stack Overview

- **Frontend**: React 19, Vite, Tailwind CSS, Lucide React, Framer Motion, Lenis, GSAP, Axios
- **Backend**: Node.js, Express.js, JWT Authentication, Bcryptjs, Multer, Express Rate Limit
- **Database**: MySQL & Sequelize ORM (`mysql2`)

## ⚡ Quick Start (Local Development)

### 1. Clone & Setup Backend
```bash
cd backend
npm install
npm run seed     # Initializes default Admin credentials & sample active job listings
npm run dev      # Starts Express server on http://localhost:5005
```

### 2. Setup Frontend
```bash
cd frontend
npm install
npm run dev      # Starts React Vite server on http://localhost:5173
```
